# 🍗 ART MORINA — Official Owner of KFC™ (real) 🍗

A deliberately cringe fan site for Art Morina: owner of KFC (self-appointed), your local host,
inventor of The Hand Sign™. Plain HTML/CSS/JS, no build step, no dependencies.

## Run it on localhost

Pick one (from inside this folder):

```bash
node server.js                 # → http://localhost:6767  (comes with a cringe banner)
python3 -m http.server 6767    # → http://localhost:6767
npx serve -l 6767              # → http://localhost:6767
```

Or just double-click `index.html`. Everything works offline except the Google Fonts.

## What's inside

- **Hero**: his photo with a crown, a drumstick and *deal-with-it* shades that drop in
- **About**: LinkedIn-parody profile + viral post + Rizz-o-meter™
- **A.I. Art Gallery** (Art Intelligence™): 8 pieces, click to open, download button
- **Menu**: add to cart, order is sent to localhost, never arrives
- **Secret Recipe**: click the black bars to declassify
- **Hand Sign Academy**, **Reviews**, **Guestbook** (saved in your browser)
- 🎵 8-bit theme song, 🔊 CEO voice (text-to-speech), chicken sound effects
